# 评测协议

真实数据查询文件采用 JSONL，每行至少包含：

```json
{"query":"雨夜站台告别","relevance":{"movie_a_000123":3,"movie_a_000124":1}}
```

相关等级建议：3=高度相关，2=相关，1=部分相关，0=不相关。标注者应在不知道模型排序的情况下先确定相关片段。

数据划分必须以 `media_id` 或完整连续场景为组，禁止把同一连续场景的相邻字幕随机拆到调参与测试两侧。字段权重、融合权重、阈值和 Top-K 只能在训练/验证部分确定；测试集仅用于最终报告。

默认输出 Recall@1、Recall@5、MRR@5、nDCG@5、平均查询延迟和索引构建时间。小型模拟集仅用于工程回归，不进行显著性声称。真实查询数量足够时，才能考虑课程所述的成对比较或置信区间。
