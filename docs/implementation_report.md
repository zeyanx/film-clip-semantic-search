# 影视剪辑素材语义搜索系统实现说明

本文是当前工程实现记录，不是最终课程论文，也不提前形成真实性能结论。

系统以 TF-IDF 和余弦相似度作为离线可解释基线，并提供本地句向量、CLIP 关键帧和加权融合接口。数据层保存片段、时间码、媒体标识、媒体类型和权限依据；媒体层解析 SRT/VTT，在 FFprobe/FFmpeg 可用时支持固定窗口和关键帧；索引层支持持久化与增量更新；页面层提供搜索、导入、模型、评测和版权说明。

当前实际实验只有自建模拟数据。TF-IDF 完整字段与仅字幕消融在 8 条简单查询上都取得满分，说明这组查询无法区分二者，也说明后续真实实验需要更困难的同义改写、跨语言、纯画面和干扰片段。句向量和融合配置因为没有本地模型而未运行；系统保留 `not_run` 状态，而不是复制 TF-IDF 指标。

课程知识与实现的详细对应位于项目外层 `work/course_knowledge.md`、`work/course_concept_index.md`、`work/project_knowledge_mapping.md` 和 `work/design_specification.md`。最终论文只能在获得合法真实媒体、完成独立标注并重新运行实验之后，根据实际数据形成结论。
